## Last ned

* **PPTimagePoint-zip** (under Assets): manifest, installasjonsskript for Mac og Windows og en LES-MEG-fil.
* **manifest.xml**: bare manifestet, til PowerPoint på nett.

## Installere

**Mac:** pakk ut zip-filen og dobbeltklikk `install-mac.command` (høyreklikk > Åpne hvis Mac stopper den). Start PowerPoint på nytt.

**Windows:** pakk ut zip-filen og dobbeltklikk `install-windows.bat` (Mer info > Kjør likevel hvis Windows stopper den). Start PowerPoint på nytt.

**PowerPoint på nett:** Hjem > Tillegg > Flere tillegg > Mine tillegg > Last opp mitt tillegg, og velg `manifest.xml`.

Deretter: marker et bilde, klikk **Picture Tools** på Hjem-fanen og **Get selected picture**.

Tillegget kjører fra GitHub Pages og trenger internett.
